# tesselgui-tokens

Design tokens for [TesselGUI](https://github.com/SeanShaffer88/TesselGUI), version 1.4.0. Generated from `docs/tokens.json`. Do not edit.

```js
import { palettes, syntax } from 'tesselgui-tokens';
palettes.dark.background; // '#010409'
```

```css
@import 'tesselgui-tokens/tessel.css';
```

Themes: `dark` (default), `light` and `highContrast`. Set `data-theme="light"` or `data-theme="high-contrast"` on `:root`. Licensed CC-BY-4.0 AND MIT: design under CC BY 4.0, code under MIT.
