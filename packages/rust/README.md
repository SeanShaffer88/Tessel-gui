# tesselgui-tokens

Dependency-free Rust constants for [TesselGUI](https://github.com/SeanShaffer88/TesselGUI), version 2.0.0. Generated from `docs/tokens.json`. Do not edit.

Colors are `[u8; 3]` sRGB. Use `DARK`, `LIGHT` or `HIGH_CONTRAST`, and `SYNTAX_DARK` or `SYNTAX_LIGHT` for code text. Convert with your toolkit, for example `egui::Color32::from_rgb(r, g, b)`. Licensed CC-BY-4.0 AND MIT.
